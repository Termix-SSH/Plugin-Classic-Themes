## Overview

Classic Themes holds the color themes that ship with Termix. It is always installed. You can pick a theme in Settings, Appearance, but not remove the plugin.

Read the [docs](https://docs.termix.site/plugins/classic-themes) to learn how it works.

<br />

## Features

- Light and dark themes
- Dracula, Catppuccin, Nord, Solarized, Tokyo Night, One Dark and Gruvbox
- CSS only, no code runs

## Support

Bugs and ideas for Classic Themes go in this repo: [report a bug](https://github.com/Termix-SSH/Plugin-Classic-Themes/issues/new?template=bug_report.yml) or [request a feature](https://github.com/Termix-SSH/Plugin-Classic-Themes/issues/new?template=feature_request.yml). Report an issue on the plugin's page in the Plugins tab fills in your versions for you.

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.

Add as much detail as you can, in English if possible. For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
